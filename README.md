# KiranaManagement

A multi-tenant SaaS platform for grocery / kirana stores. Every store
self-registers, waits for platform approval, and after approval manages its
**sales, purchases, online sales, order management, and accounting** from one
place — while a central Super Admin governs onboarding and platform health.

## Documentation
- [Product Requirements Document (PRD)](docs/PRD.md) — vision, scope, personas,
  functional & non-functional requirements, data model, phasing, and risks.

## Status
Early planning. The PRD is the first artifact; technical design and
implementation follow.
